This user manual explains how to use IAE for creating configurations, creating projects, running student ZIP submissions, viewing results, and exporting reports.

1. Getting Started

IAE is a desktop application that helps instructors process programming assignments. The application can extract student ZIP files, compile and run source code, compare the actual output with the expected output, and show the results in a table.

  1. Create or import a configuration.
  2. Create a new project.
  3. Select the folder that contains student ZIP files.
  4. Select the expected output file.
  5. Run the project.
  6. Review or export the results.
Before creating a project, at least one configuration must exist.

2. Configurations

Configurations define how student code should be compiled and executed. Open the configuration screen from Configurations > Manage Configurations.

Creating a configuration

  1. Click + New Configuration.
  2. Enter a configuration name.
  3. Enter the programming language.
  4. Select whether compilation is required.
  5. Enter compile command and compile arguments if needed.
  6. Enter run command and run arguments.
  7. Enter the expected source file name.
  8. Click Save Configuration.

Editing and deleting configurations

Select a configuration from the list. Then use Edit or Delete. A configuration that is used by a project may not be deleted.

Import and export

Use Import JSON to import a configuration from a JSON file. Use Export JSON to save the selected configuration as a JSON file.

3. Creating a Project

A project stores the selected configuration, ZIP directory, expected output file, optional run arguments, status, and results.

  1. Click File > New Project or the New Project button.
  2. Enter the project name.
  3. Select a configuration.
  4. Click Browse and select the folder that contains student ZIP files.
  5. Click Browse and select the expected output text file.
  6. Enter optional run arguments if the assignment needs them.
  7. Click Create Project.
Field Description
Project Name Name of the assignment project.
Configuration The compile and run profile used for the project.
ZIP Directory The folder containing student ZIP submissions.
Expected Output The correct output file used for comparison.
Run Arguments Optional command line arguments.

4. Running a Project

Open a project by double-clicking it from the main table or by selecting it and clicking Open Project.

  1. Check the selected ZIP directory.
  2. Click Change if you need to select another ZIP folder.
  3. Click RUN.
  4. Wait until the progress bar finishes.

IAE extracts each ZIP file, finds the source file, compiles it if required, runs the program, compares the output, and saves the result.

5. Viewing Results

After running a project, the result table shows one row for each student submission.

Column Description
Student ID The student ID read from the ZIP file name.
Compile Shows whether compilation passed, failed, or was skipped.
Run Shows whether the program ran successfully, failed, timed out, or was skipped.
Output Match Shows whether the actual output matches the expected output.
Detail Click View to see detailed result information.

Filtering results

The filter combo box can show All, Pass, Fail, Compile Error, or Timeout results.

Detail window

The detail window shows compile errors, run errors, expected output, and actual output.

CSV export

Click Export CSV to save the project results as a CSV file.

6. Open and Save Projects

Projects are listed on the main screen. When the application is opened again, saved projects are loaded from the database.

  • Double-click a project to open it.
  • Or select a project and click Open Project.

When a project is opened, its name, configuration, ZIP directory, summary, and previously saved results are shown.

Project data and results are stored by the application, so they can be accessed later.
