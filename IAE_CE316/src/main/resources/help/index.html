IAE - Integrated Assignment Environment

1. Creating a Project

Click File > New Project. Enter the project name, select a configuration, choose the student ZIP folder, and set the expected output file.

2. Managing Configurations

Open Configurations > Manage Configurations to create, edit, or delete language configurations. You can also import/export them as JSON files.

3. Running a Project

Open a project and click RUN. IAE will extract each student ZIP, compile/run the code, and compare the output.

4. Viewing Results

After running, the results table shows each student's compile, run, and output comparison status. Click View on any row for details.
